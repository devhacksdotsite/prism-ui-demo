# Prism UI Demo

A static landing page showcasing [prism-ui](https://github.com/devhacksdotsite/prism-ui) components in a real-world context.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

Static output goes to `dist/` — deploy anywhere (Netlify, Vercel, S3, GitHub Pages, etc.).

## Preview production build

```bash
npm run preview
```
